# Portfolio-DVA

Personal portfolio site built with HTML and CSS. It showcases projects, skills, and profile information—focused on data visualization and analytics work (Tableau dashboards, storytelling).

## Run locally

From the repository root:

```sh
./serve.sh
```

The script will print the URL it is using, for example:

```
Serving on http://localhost:8000
```

If port 8000 is already in use, it will try the next available port (8001, 8002, etc.).

If you prefer a direct command without the script:

```sh
cd Portfolio-DVA && python3 -m http.server 8000
```
